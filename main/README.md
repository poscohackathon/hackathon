# AI 기반 열연 생산 시뮬레이션 및 최적 운영 의사결정 시스템

**팀 그럴싸이언스** · 제철소 AI 해커톤

실제 열연 공장의 압연 데이터를 학습한 AI로 가상 압연 공정을 만들고, 생산 전에 압하 배분을 시험해 설비 부담이 가장 적은 운영 조건을 추천합니다.

```
압연 조건 입력 → [AI 하중 예측] F1~F5 하중 → [최적화] 압하 배분 추천 → [시뮬레이터] 현재 vs 추천 비교
```

## 결과 요약

**하중 예측** (처음 보는 코일 20%로 평가, 코일 단위 분할)

| 모델 | R² | MAE | 평균 오차율 |
|---|---|---|---|
| 물리식 M3 (논문 재현, 기준선) | 0.946 | 1.24 MN | 7.2% |
| MLP (PyTorch) | 0.988 | 0.56 MN | 3.2% |
| **GBDT (단조 제약, 최종)** | **0.992** | **0.44 MN** | **2.5%** |

- 물리식 대비 오차 **64% 감소**. 가장 어려운 F5 스탠드는 R² 0.38 → 0.94
- 단조 제약: "더 눌렀는데 하중이 줄어든다"는 물리적으로 틀린 예측을 0%로 막음

**압하 배분 최적화**

| 코일 | 최대 이용률 | 최대 하중 |
|---|---|---|
| 2744 (메인 시연, F1 병목) | 0.744 → 0.606 (−18.5%) | 27.1 → 20.8 MN |
| 2599 (보조 시연, F1 한계 직전) | 0.976 → 0.862 (−11.7%) | 35.5 → 29.7 MN |

- 무작위 200코일: 최대 이용률 감소 중앙값 1.0%, **11%의 코일이 5% 넘게 개선**(최대 16.3%)
- 이용률 = 하중 ÷ 스탠드별 과거 최대 하중(상위 0.5%). 실제 설비 정격이 없어 정한 가정값

## 시뮬레이터 (시연)

**https://greatscience.streamlit.app**

설치 없이 브라우저에서 바로 열 수 있습니다. 저장소의 `pjh/app.py`는 초기 시제품이며, 최종 시연은 위 링크 앱입니다.

## 실행 방법

저장소 맨 위 폴더에서 실행합니다.

```bash
pip install -r main/requirements.txt

python main/main.py          # 데이터 정리 → 성능 평가 → 최적화 (약 1분)
```

`main/main.py` 실행 결과는 `main/outputs/`에 저장됩니다.

| 파일 | 내용 |
|---|---|
| `model_performance.csv` | 세 모델의 R², MAE, 오차율, 단조 위반율 |
| `stand_r2.csv` | 스탠드별 R² |
| `actual_vs_pred.png` | 실제-예측 산점도 (물리식 vs GBDT) |
| `demo_coils.csv` | 시연 코일의 스탠드별 현재·추천 압하율, 하중, 이용률 |
| `optimization_200coils.csv` | 무작위 200코일 최적화 결과 |

    force_model.py     최종 하중 예측 모델 (GBDT, 학습률 0.1, 나무 1,400개, 단조 제약)

## 방법

1. **데이터:** Nucor Steel Decatur 사상압연(F1~F5), 2023~2024년, 코일 7,797개 × 5스탠드 = 38,980행, 강종 10종. 정리 후 7,533코일.
2. **기준선:** 논문(Udofia et al., *Metals* 2025, 15(12), 1346)의 물리식 M3, F = A·ε̇ⁿ·w·ℓ를 재현했습니다(로그 기준 R² 0.946, 논문과 같음).
3. **AI 모델:** 입력은 강종, 스탠드, 입·출측 두께, 폭, 롤 반경, 온도, 그리고 물리 변수(압하율, 접촉 길이, 변형률, 변형 속도)예요. GBDT와 MLP를 비교했고, GBDT는 가설 검증으로 튜닝했어요(나무 600 → 1,400개, 학습률 0.05 → 0.1). 단조 제약도 넣었어요.
4. **평가:** 같은 코일이 학습과 평가에 섞이지 않도록 코일 단위로 분할했어요. 논문의 행 단위 무작위 분할보다 엄격한 방식이에요.
5. **최적화:** 강종, 폭, F1 입측 두께, 최종 두께는 고정하고 F1~F5 압하율만 바꿔요. 과거 운영 범위(압하율 1~99%) 안에서 "최대 이용률 + 0.5 × 이용률 편차"가 가장 낮은 배분을 고릅니다.

## 한계

- 과거 운영 범위 밖의 조건과 처음 보는 강종은 예측을 믿기 어려워 추천하지 않습니다.
- 이용률 기준 하중은 가정값입니다. 이용률이 줄어도 최대 하중(MN)은 늘어나는 코일이 있습니다(뒷단 부담을 앞단으로 옮기는 경우). 자세한 내용: [ojs/이용률과_최대하중.md](../ojs/이용률과_최대하중.md)
- 품질과 에너지 데이터가 없어 품질 영향과 에너지 절감은 직접 평가하지 못했습니다.
- 추천은 자동 제어가 아니라 운영자 판단을 돕는 참고 정보입니다.
