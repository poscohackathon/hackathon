## 한 줄 요약
미국 Nucor 공장의 사상압연 데이터 38,980건으로 **"하중 = 113.1 × 변형 속도^0.314 × 폭 × 접촉 길이"**라는 간단한 식을 만들었어요. 맞힌 정도는 R² 0.946이에요. 온도는 식에 넣으면 오히려 이상한 결과가 나와서 뺐어요.

- **저자:** 미국 콜로라도 광업대(Colorado School of Mines). 연속주조·압연 분야로 유명한 Brian G. Thomas 교수팀이에요.
- **발표:** *Metals* 2025년 12월 8일
- **라이선스:** 논문 첫 쪽에 CC BY 4.0이 명시돼 있어요. 출처만 밝히면 써도 돼요.

## 1. 왜 압연 하중 예측이 중요한가 (서론)
→ 기획서의 **문제 정의**에 그대로 쓸 수 있어요.
- **사고 위험:** 하중이 두께 감소량과 맞지 않으면 스탠드 사이에 강판이 쌓여요. 그러다 라인 밖으로 튀어나가는 사고를 **코블(cobble)**이라고 해요. 설비가 망가지고 작업자도 위험해져요.
- **롤 수명:** 하중이 클수록 롤이 빨리 닳아요. 롤 표면이 상하면 제품 표면 결함으로 이어져요.
- **품질:** 하중 예측이 틀리면 두께 불량이 생겨요.

## 2. 기존 방법의 한계 (2장 선행 연구)
→ "왜 빠른 AI 모델이 필요한가"의 근거예요.

| 방법 | 장점 | 한계 |
|---|---|---|
| 실험실 모델 | 원리를 이해하기 좋음 | 실제 공장보다 하중을 **20~40% 낮게** 예측. 실험실 롤은 작고 느림 |
| 유한요소해석(FEA) | 오차 5~10%로 정확함 | 스탠드 하나 계산에 **4~24시간**. 실시간으로 쓸 수 없음 |
| 회귀 모델 | 빠르고 해석이 쉬움 | 변수끼리 서로 얽혀 있어 엉뚱한 계수가 나옴(아래 5장) |
| 신경망·머신러닝 | 복잡한 관계도 잘 맞힘 | 속을 알 수 없음. 학습 범위 밖에서는 믿기 어려움 |

**우리 주제와 직접 관련된 선행 연구** (발표에서 "선례가 있다"는 근거로 쓸 수 있어요)
- **Jia 외:** 사상압연 스탠드별 **하중 배분을 다목적 최적화**했어요. 목표는 하중 여유 균형, 롤 마모, 판 형상이었어요. 우리 최적화와 같은 방향이에요.
- **Yang 외:** 신경망으로 하중을 예측한 뒤, 그걸로 **압연 스케줄을 최적화해 하중 배분을 개선**했어요.
- **Barrios 외:** 물리 모델이 85%를 맞히고, 나머지 오차 15%를 신경망이 배우게 했어요. zoy의 **하이브리드 모델과 같은 발상**이에요.

## 3. 공장과 데이터 (3장)
**공정 순서 (Nucor Decatur 공장)**

전기로 2기(고철을 녹임, 150~175톤) → **연주기 2대(데이터의 S/N)** → 98mm 슬래브 → 터널로에서 재가열 → 조압연(약 27mm로) → **사상압연 F1~F5 (이 논문의 대상)** → 냉각대 → 권취(코일로 감기)

**각 값은 이렇게 측정했어요**

| 값 | 측정 방법 |
|---|---|
| 하중 | 스탠드 기둥에 넣은 **로드셀**(힘 센서) |
| 두께 | **X선 두께계**, 스탠드 입·출측 |
| 온도 | **비접촉 광학 고온계**. 표면 온도예요(속 온도 아님) |
| 폭 | 고속 카메라로 판 가장자리 감시 |
| 롤 반경 | 주기적으로 측정해서 마모를 반영 |
| **속도** | **F5 출측에서만 측정했고, 데이터에는 없어요** |

**공장의 원래 하중 제어 방식** (→ 기획서의 **현업 적용**에 좋은 근거예요)
1. 수학 모델로 처음 하중을 정해요.
2. 두께가 측정되면 피드백으로 바로 보정해요.
3. 예측과 실제의 차이는 **머신러닝으로 다음 코일 설정에 반영**해요.
4. 다만 신경망은 **익숙한 범위 안에서만 믿을 수 있어서**, 코일 사이 조정은 작게만 허용해요. 특히 속도가 빠른 뒤쪽 스탠드는 더 작게 조정해요.

→ 실제 공장도 이미 AI 보정을 쓰고 있고, **범위 제한** 관행도 우리 계획과 같아요.

**데이터 정제:** 약 4만 건 중 음수 하중 같은 명백한 오류 10건 미만만 지워서 38,980건이 남았어요. 이상치 제거를 따로 하지 않은 zoy의 판단과 맞아요.

**강종 10종:** 저탄소강, 중탄소강, HSLA(미량 합금으로 강도를 높인 강)로 나뉘어요.
- ⚠️ 논문 안에서 **강종 분류가 두 번 다르게 나와요.** 3장에서는 중탄소가 2·5·8번인데, 8장에서는 4·5·6번이에요.
- 발표에서는 그룹 이름 대신 **Grade 번호로만** 말하는 게 안전해요.

## 4. 기본 이론 (4장): 하중을 결정하는 식

**핵심 식**

> **하중 = 평균 변형 저항 × 폭 × 접촉 길이**

- **변형 저항:** 소재가 눌리지 않으려고 버티는 힘(MPa)이에요. 강종이 단단할수록, 온도가 낮을수록, 빨리 누를수록 커져요.
- **폭 × 접촉 길이:** 롤과 판이 닿는 면적이에요.

**식에 들어가는 값들**

| 이름 | 식 | 쉬운 뜻 |
|---|---|---|
| 접촉 길이 ℓ | √(롤 반경 × 압하량) | 롤과 판이 닿는 길이. 많이 줄일수록 길어져요 |
| 변형률 ε | ln(입측 두께 / 출측 두께) | 얼마나 많이 눌렀나 |
| 출측 속도 v | v₁ × (F1 입측 두께 / 출측 두께) | **질량 보존:** 판이 얇아지면 그만큼 빨라져요 |
| 변형 속도 ε̇ | 변형률 × 속도 / 접촉 길이 | 얼마나 **빨리** 눌렀나 |

⭐ **중요:** 논문은 속도를 측정값 없이 **F1 입측 속도 1,096 mm/s, F1 입측 두께 25.8mm라는 평균값으로 고정**해서 계산했어요. "이 기준값을 바꿔도 결과에 영향이 거의 없었다"고 해요. 우리 데이터로도 똑같이 계산할 수 있다는 뜻이에요(아래 '의미' 1번).

## 5. 데이터에서 발견한 것 (5장): 이 논문의 핵심

**스탠드별로 따로 보면 상식대로 움직여요.**
- 온도가 높을수록 하중이 작아요(소재가 무르니까).
- 하중은 폭에 정비례해요.
- 빨리 누를수록 하중이 커져요.

**그런데 전체를 한꺼번에 보면 거꾸로 보여요.** F1은 가장 뜨거운데 하중도 가장 커요.
- 이유는 **현장 운영 방식**이에요. 뒤로 갈수록 판이 식어서 단단해져요. 그래서 현장은 특정 스탠드에 하중이 몰리지 않도록 **앞 스탠드에서 많이 줄이고 뒤에서 적게 줄여요.**
- 그 결과 온도, 변형률, 접촉 길이, 스탠드 번호가 **한 덩어리로 같이 움직여요.**
- 우리 데이터로 계산해 보니 온도와 스탠드 번호의 상관이 **−0.97**, 온도와 접촉 길이의 상관이 **0.92**였어요.
- 변수끼리 이렇게 얽힌 것을 **다중공선성**이라고 해요. 이러면 회귀 분석이 "온도 때문인지 압하량 때문인지"를 구분하지 못해요.

## 6. 모델 결과 (6~8장)

| 모델 | 들어가는 것 | R² | 판정 |
|---|---|---|---|
| M0 | 온도 + 변형률 + 변형 속도 + 폭 + 접촉 길이 전부 | 0.61 | ❌ 계수가 물리적으로 말이 안 됨 |
| M1 | 온도 + 변형 속도 + 폭 + 접촉 길이 | 0.948 | ❌ "온도가 오르면 하중도 오른다"는 계수가 나옴 |
| M2 | 변형 속도 + 폭 + 접촉 길이 | 0.947 | 괜찮음(계수 4개) |
| **M3** | **변형 속도 + 폭 × 접촉 길이(지수를 1로 고정)** | **0.946** | ✅ **최종 채택.** 계수 2개뿐 |

- **최종 식 M3:** 하중[N] = 113.1 × 변형 속도^0.314 × 폭[mm] × 접촉 길이[mm]
- **검증:** 데이터를 **행 단위로 무작위 80:20** 나눴어요. 학습 R² 0.945, 평가 R² 0.945, 평가 오차(RMSE) 1.65 MN이에요.
- **강종별 모델:** 강종마다 따로 맞추면 R² 0.948~0.981로 조금 좋아져요. 그런데 계수가 2개에서 20개로 늘어나는 것에 비해 이득이 작아서, 논문은 하나의 통합 식을 추천해요.
  - 강종별 변형 속도 지수: 0.285~0.364 (Grade05가 0.362, Grade06이 0.364로 가장 민감)

## 7. 한계 (9~10장)
- **식이 잘 맞는 이유가 곧 약점이에요.** 온도가 떨어지면 하중이 늘고, 압하량이 줄면 하중이 줄어요. 둘이 서로 상쇄돼서 온도를 빼도 잘 맞는 거예요.
- 그래서 논문은 직접 경고해요. **"온도와 변형률이 평소 패턴에서 크게 벗어나면 정확도가 떨어진다."**
- **쓸 수 있는 범위:** 온도 1,182~1,258K, 변형률 0.34~0.50, 변형 속도 15~405/s
- **다른 공장 비교:** 다른 논문의 측정값에 적용했더니 오차가 −17%, +11%였어요. 조건이 많이 달라도 대략은 맞아요.
- **향후 과제:** 강종·온도·변형률 효과를 따로 분리하려면 **비선형 모델**과 다양한 조건의 데이터가 필요하다고 해요. 우리 AI 모델이 이 "향후 과제"에 해당한다고 말할 수 있어요.

# ⭐ 우리 프로젝트에 주는 의미

### 1. 논문 식을 우리 데이터로 그대로 재현할 수 있어요 (zoy README 정정)
zoy README에는 "속도가 없어서 논문 식을 그대로 쓸 수 없다"고 적혀 있어요. 하지만 논문도 속도를 가정값으로 계산했어요. 같은 방법으로 우리 데이터(38,980행)에 직접 계산한 결과예요.

| | R² | 평균 오차 |
|---|---|---|
| 논문 M3 계수 그대로 | 0.942 | 1.31 MN |
| 우리 데이터로 다시 맞춤 | 0.944 | 1.27 MN (지수 0.314로 **논문과 똑같이** 나옴) |
| (참고) zoy의 물리 기반 회귀 | 0.948 | 1.12 MN |

- **발표 포인트:** "논문의 식을 공개 데이터로 재현해 R² 0.94를 확인했고, 그 기준선보다 AI가 오차를 X% 줄였다"고 말할 수 있어요. 신뢰도가 크게 올라가요.
- 모델 확인 단계에서 기준선에 **논문 M3를 추가**하는 게 좋아요.

### 2. 최적화할 때 가장 조심해야 할 점
우리 최적화는 **압하 배분을 바꾸는 것**이에요. 그런데 논문이 경고한 "평소 패턴에서 벗어나면 정확도가 떨어진다"가 바로 이 상황이에요. AI 모델도 마찬가지예요.
- **과거 운영 범위 안에서만 추천**해야 해요. 기획서에 이미 들어가 있어요.
- **단조 제약**이 더 중요해져요. 압하율을 올리면 하중도 오르도록 모델을 묶는 거예요.
- **"온도는 고정"이라는 가정**을 발표의 한계에 꼭 적어야 해요. 실제로는 배분을 바꾸면 온도도 바뀌어요.

### 3. 현장은 이미 하중 균형을 맞추고 있어요
논문에 따르면 Nucor는 이미 하중이 몰리지 않게 운영하고 있어요. 그래서 "현장은 균형을 신경 쓰지 않는다"처럼 말하면 과장이에요.
- **맞는 표현:** "경험과 설정표 기반의 배분을, **코일마다 데이터로 맞춤 추천**해 보완한다"
- zoy의 병목 분석이 근거가 돼요. 코일마다 한계에 가장 가까운 스탠드가 다르다는 결과예요.

### 4. 우리 검증 방식이 더 엄격해요
- 논문은 행 단위로 무작위 분할했어요. 그러면 같은 코일의 F1~F5가 학습과 평가에 섞여요.
- 우리는 **코일 단위**로 나눴어요.
- **발표 포인트:** "더 엄격한 방식으로 평가했는데도 논문보다 정확하다"고 말할 수 있어요.

### 5. 논문 Table 3 숫자는 인용하지 마세요
논문의 스탠드별 요약표(Table 3)는 부록 데이터와 맞지 않아요. 논문 안에서도 변형률이 Table 3에서는 0.35→0.48로 늘고, 9장에서는 0.48→0.35로 줄어요.

| 항목 | 논문 Table 3 | 실제 데이터 (F1 → F5) |
|---|---|---|
| 접촉 길이 | 22.5 → 8.9 mm | **68.5 → 15.5 mm** |
| 변형률 | 0.35 → 0.48 | **0.58 → 0.19** |
| F1 입측 두께 | 25.8 mm | **27.7 mm** |
| F1 하중 | 24.2 MN | **26.0 MN** |

→ 발표에는 **우리가 데이터로 직접 계산한 값**만 쓰세요. 논문에서 인용할 건 최종 식, R² 0.946, 결론 정도면 충분해요.

### 6. 발표에 쓸 수 있는 근거 문장
- 문제 정의: "하중 예측 오류는 코블 사고, 롤 마모, 두께 불량으로 이어진다" (서론)
- 필요성: "정밀한 시뮬레이션(FEA)은 스탠드 하나에 4~24시간이 걸려 현장 의사결정에 쓸 수 없다" (2장)
- 현업 적용: "실제 공장도 머신러닝으로 하중 설정을 보정하며, 학습 범위 안에서만 조정한다" (3장)
- AI의 역할: "논문이 향후 과제로 남긴 비선형 효과를 AI가 학습한다" (10장)
