# 용어 정리: 열연 사상압연 하중 예측 프로젝트

압연을 처음 접하는 팀원을 위한 용어 사전이에요. 공정 순서대로 먼저 읽고, 그다음 숫자와 모델 용어를 보면 이해하기 쉬워요.
논문 내용은 [논문요약_Udofia2025.md](논문요약_Udofia2025.md)에 있어요.

## 먼저 큰 그림: 철이 판이 되기까지
```
고철 ─▶ [전기로] 녹임 ─▶ [연속주조] 굳혀서 두꺼운 판(슬래브) ─▶ [가열로] 다시 데움
     ─▶ [조압연] 대충 얇게 ─▶ [사상압연 F1~F5] 정확한 두께로 ─▶ [냉각대] 식힘 ─▶ [권취] 둘둘 말아 코일로
```
우리 프로젝트와 논문은 이 중 **사상압연 F1~F5** 구간만 다뤄요.

---

## 1. 공정·설비 용어

| 용어 | 쉬운 설명 |
|---|---|
| **압연** | 뜨겁거나 차가운 철을 **두 개의 롤 사이로 통과시켜 눌러서 얇게 펴는 것**. 밀대로 반죽을 미는 것과 비슷해요 |
| **열간압연(열연)** | 철이 **빨갛게 달아 있을 때(약 900~1,300℃)** 하는 압연. 철이 물러서 크게 줄이기 쉬워요. 우리 데이터가 이거예요 |
| 냉간압연(냉연) | 열연한 판을 **식힌 뒤 상온에서** 한 번 더 얇고 매끈하게 미는 것. 우리와는 다른 공정이에요 |
| **슬래브** | 쇳물을 굳혀 만든 **두꺼운 직사각형 철판 덩어리**. Nucor는 98mm 두께예요(보통 공장은 200mm 이상) |
| 전기로 | 고철을 **전기 불꽃(아크)으로 녹이는 로**. 참고로 포스코는 주로 철광석을 녹이는 고로를 써요 |
| **연속주조 / 연주기** | 쇳물을 틀에 부어 **끊김 없이 슬래브로 굳히는 설비**. Nucor는 2대이고, 데이터의 `S`, `N`이 어느 연주기인지를 나타내요 |
| 가열로 / 터널로 | 슬래브를 압연하기 좋은 온도로 **다시 고르게 데우는 긴 화로** |
| **조압연** | 사상압연 전에 **두께를 크게 대충 줄이는 단계**. Nucor는 98mm → 약 27mm |
| **사상압연** | 조압연 다음에 **목표 두께까지 정밀하게 마무리하는 단계**. 사상(仕上)은 "마무리"라는 뜻이에요. 영어로 Finishing mill이라 F1, F2…로 불러요 |
| **스탠드** | 롤 한 세트가 들어 있는 **압연기 한 대**. 사상압연은 스탠드 5대가 일렬로 서 있고, 판이 F1→F5를 차례로 지나며 조금씩 얇아져요 |
| **작업 롤 / 받침 롤** | 작업 롤은 **판에 직접 닿아 누르는 롤**(반경 약 30~40cm)이에요. 받침 롤은 그 뒤에서 작업 롤이 **휘지 않게 받쳐 주는 더 큰 롤**이에요 |
| 냉각대 | 마지막 스탠드를 나온 판에 **물을 뿌려 식히는 긴 컨베이어** |
| **권취 / 코일** | 길고 얇아진 판을 **두루마리 휴지처럼 둥글게 마는 것**이 권취이고, 말린 덩어리가 코일이에요. 데이터의 코일 하나 = 슬래브 하나에서 나온 제품 하나예요 |
| **코블(cobble)** | 스탠드 사이에서 판이 **엉키거나 튀어나가는 사고**. 설비가 부서지고 사람이 다칠 수 있어요. 하중 예측이 틀리면 생길 수 있어요 |
| 롤 마모 | 롤이 계속 눌러 **닳는 것**. 하중이 클수록 빨리 닳고, 닳으면 교체해야 해요 |

스탠드 하나를 옆에서 보면 이래요.
```
            [ 받침 롤 ]
            ( 작업 롤 )
 두꺼운 판 ━━━━━━━━━━▶━━━━━━ 얇아진 판   → 다음 스탠드로
            ( 작업 롤 )
            [ 받침 롤 ]
       입측(들어가는 쪽)    출측(나오는 쪽)
```

## 2. 측정 장비·제어 용어

| 용어 | 쉬운 설명 |
|---|---|
| **로드셀** | **힘을 재는 센서**. 체중계 속 센서와 원리가 같아요. 하중을 이걸로 측정해요 |
| X선 두께계 | X선을 쏴서 **판 두께를 닿지 않고 재는 장비** |
| 광학 고온계 | 뜨거운 물체가 내는 빛으로 **온도를 닿지 않고 재는 장비**. 그래서 데이터의 온도는 판 **표면** 온도예요 |
| 피드백 제어 | 측정값을 보고 **바로바로 설정을 고치는 방식**. 에어컨이 실내 온도를 보며 세기를 조절하는 것과 같아요 |

## 3. 압연 변수 (데이터 컬럼과 계산값)

| 용어 | 쉬운 설명 | 우리 데이터에서는 |
|---|---|---|
| **하중 (압연력)** | 롤이 판을 **위아래로 누르는 힘**. 우리가 예측할 값이에요 | F1 평균 26 MN → F5 10 MN |
| N, **MN** | 힘의 단위. 1 MN(메가뉴턴) = 100만 N이고, **약 100톤 무게로 누르는 힘**이에요 | 26 MN ≈ 약 2,650톤이 누르는 힘 |
| **입측 / 출측 두께** | 스탠드에 **들어갈 때 / 나올 때** 판 두께. 앞 스탠드의 출측 = 다음 스탠드의 입측이어야 정상이에요 | F1 입측 평균 27.7mm → F5 출측 4.2mm |
| **압하량** | 한 스탠드에서 **줄인 두께**(입측 − 출측) | |
| **압하율** | 줄인 두께를 **비율로** 나타낸 것(압하량 ÷ 입측). 10mm에서 5mm면 50% | F1 43% → F5 17% |
| **압하 배분** | 전체 두께 감소량을 **F1~F5에 어떻게 나눌지**. 우리 최적화가 바꾸는 값이에요 | |
| 판 폭 | 판의 **가로 너비** | 936~1,720mm |
| 롤 반경 | 작업 롤의 **반지름**. 닳으면 작아져요 | 약 300~400mm |
| **접촉 길이** | 롤과 판이 **실제로 맞닿아 있는 길이**. √(롤 반경 × 압하량)으로 계산해요. 많이 줄일수록 길어요 | F1 68mm → F5 15mm |
| **변형률** | **얼마나 많이** 눌렀나를 나타내는 값. ln(입측 ÷ 출측)으로 계산해요 | |
| **변형 속도** | **얼마나 빨리** 눌렀나. 단위는 "/초"예요. 뒤 스탠드일수록 판이 빨라서 커져요 | F1 16/s → F5 119/s (논문 방식으로 계산) |
| **질량 보존** | 1초에 들어간 철의 양 = 나온 양. 그래서 **판이 얇아지면 그만큼 빨라져요**. 호스 끝을 누르면 물이 빨라지는 것과 같아요 | 속도를 이 원리로 계산해요 |
| **변형 저항 (유동 응력)** | 소재가 **눌리지 않으려고 버티는 힘**. 단단한 강종, 낮은 온도, 빠른 누름일수록 커져요 | 강종별 306~466 MPa |
| MPa | 넓이당 힘의 단위. 1 MPa는 **손톱만 한 1cm² 위에 약 10kg**이 누르는 정도예요 | 300 MPa ≈ 1cm²에 3톤 |
| K (켈빈) | 온도 단위. **℃ = K − 273** | 1,270K ≈ 997℃ |

**핵심 관계 한 줄:** 하중 ≈ **변형 저항 × 폭 × 접촉 길이**. 즉 "소재가 얼마나 단단한가 × 누르는 면적"이에요.

## 4. 강종 용어

| 용어 | 쉬운 설명 |
|---|---|
| **강종 (Grade)** | 강철의 **종류**. 성분이 달라 단단한 정도가 달라요. 데이터에서는 Grade01~10으로 이름을 가렸어요 |
| 저탄소강 | 탄소가 적어 **무르고 가공이 쉬운** 일반 강 |
| 중탄소강 | 탄소가 더 많아(최대 0.3%) **더 단단한** 강 |
| HSLA (고강도 저합금강) | 니오븀, 바나듐, 티타늄 같은 원소를 **아주 조금** 넣어 강하게 만든 강. 파이프라인 등에 써요 |

⚠️ 논문 안에서 강종 분류가 두 번 다르게 나와요. 발표에서는 그룹 이름 대신 **Grade 번호로만** 말하는 게 안전해요.

## 5. 모델·통계 용어

| 용어 | 쉬운 설명 |
|---|---|
| **물리 기반 모델** | 압연 이론 식(하중 ≈ 변형 저항 × 폭 × 접촉 길이)을 바탕으로 만든 모델. **이유를 설명할 수 있어요** |
| **기준선 (baseline)** | "이것보다 나아야 의미가 있다"는 **비교 기준**. 우리는 논문 물리 식이 기준선이에요 |
| 회귀 분석 | 데이터를 보고 **식의 숫자(계수)를 맞추는 방법** |
| 계수 / 지수 | 식에 들어가는 숫자들. 논문 M3 식의 113.1이 계수이고, 0.314가 지수예요 |
| 지수 0.314의 뜻 | 변형 속도가 **2배**가 되면 하중은 2^0.314 ≈ **1.24배**가 된다는 뜻이에요 |
| 로그 변환 | 곱셈으로 된 식에 log를 씌워 **덧셈 식으로 바꾸는 요령**. 그래야 회귀 분석을 쓸 수 있어요 |
| **R² (결정계수)** | 0~1 사이의 점수이고, **1에 가까울수록 잘 맞혀요**. 0.946이면 "코일마다 하중이 달라지는 이유의 94.6%를 설명한다"는 뜻이에요 |
| **MAE (평균 절대 오차)** | 예측이 **평균적으로 몇 MN 틀렸나**. 작을수록 좋아요 |
| RMSE | MAE와 비슷한데, **크게 틀린 것에 더 큰 벌점**을 줘요 |
| **상관 (상관계수)** | 두 값이 **같이 움직이는 정도**(−1~1). 온도와 스탠드 번호는 −0.97이라 거의 완전히 반대로 움직여요 |
| **다중공선성** | 입력 변수들이 **서로 너무 붙어서 같이 움직이는 상태**. 그러면 "누구 때문인지" 구분이 안 돼요. 축구에서 두 선수가 늘 같이 뛰면 누가 골에 기여했는지 알기 어려운 것과 같아요 |
| 유한요소해석 (FEA) | 물체를 **수만 개의 작은 조각으로 나눠 각각 물리 계산**하는 정밀 시뮬레이션. 정확하지만 매우 느려요 |
| **MLP** | 가장 기본적인 **신경망(딥러닝)** 모델 |
| 경사하강법 | MLP를 **학습시키는 방법**. 오차가 줄어드는 방향(기울기)으로 조금씩 숫자를 고쳐 가요 |
| **GBDT (경사 부스팅)** | 작은 **결정 나무 여러 개를 차례로 쌓아**, 앞 나무가 틀린 부분을 다음 나무가 고쳐 가는 모델. 표 데이터에 특히 강해요. 이름은 비슷하지만 경사하강법과는 다른 방식이에요 |
| **하이브리드 모델** | **물리 식 예측 × AI 보정**. 물리 식이 큰 틀을 잡고, 놓친 부분만 AI가 배워요 |
| 과적합 | 문제집 답만 외워서 **새 문제는 못 푸는 상태** |
| **학습 / 평가 분할** | 데이터 일부로 공부(학습)시키고, **안 본 나머지로 시험(평가)**하는 것 |
| **코일 단위 분할** | 한 코일의 F1~F5를 **통째로** 학습 쪽이나 평가 쪽에 넣는 방식. 행 단위로 섞으면 같은 코일이 양쪽에 들어가 **시험 문제가 미리 새는 셈**이에요 |
| 교차검증 (5-fold) | 데이터를 5조각으로 나눠 **시험을 5번 돌려 평균**을 내는 방식. 운 좋은 결과 하나에 속지 않게 해 줘요 |
| **외삽** | 학습한 **범위 밖**을 예측하는 것. 믿기 어려워요. 그래서 시뮬레이터 입력 범위를 제한해요 |
| **단조 제약** | "압하율이 오르면 하중은 **반드시 오르거나 같다**"처럼 모델이 **한 방향으로만 움직이게 묶는 것**. 물리적으로 말이 안 되는 예측을 막아요 |

## 6. 최적화·시뮬레이터 용어

| 용어 | 쉬운 설명 |
|---|---|
| **가상 공정 / 시뮬레이터** | 실제 라인 대신 **컴퓨터 안에서 조건을 바꿔 보며 결과를 미리 보는 도구**. 우리 시스템에서는 하중 예측 모델이 이 역할을 해요 |
| **최적화** | 여러 조건을 시도해 **점수가 가장 좋은 조건을 찾는 것** |
| 점수 (목적 함수) | 최적화가 **작게(또는 크게) 만들려는 값**. 우리는 "가장 힘든 스탠드의 설비 이용률"이에요 |
| 제약 조건 | 최적화가 **반드시 지켜야 하는 규칙**. 예: 최종 두께는 목표와 같게, 압하율은 과거에 써 본 범위 안 |
| **Optuna** | 최적화 도구(파이썬 라이브러리). **똑똑한 시행착오** 방식으로, 점수가 좋았던 쪽 근처를 더 많이 시험해요 |
| 격자 탐색 | 일정 간격으로 **모든 조합을 다** 넣어 보는 가장 단순한 최적화 |
| **설비 이용률** | 하중 ÷ 그 스탠드의 과거 최대 하중. "**한계의 몇 %로 일하고 있나**"예요. 진짜 설비 한계는 데이터에 없어서 만든 **가정값**이에요 |
| 병목 스탠드 | 5개 중 **이용률이 가장 높은(가장 힘든) 스탠드** |

### AI 모델과 최적화는 역할이 달라요
가장 헷갈리기 쉬운 부분이에요. **AI 모델은 하중만 예측하고, 최적 조건은 최적화 알고리즘이 그 모델에 여러 번 물어보면서 찾아요.**

| 구성 요소 | 하는 일 | 비유 |
|---|---|---|
| **AI 하중 예측 모델** | 조건을 넣으면 F1~F5 하중을 알려줘요 | 길 하나를 주면 걸리는 시간을 알려주는 계산기 |
| **최적화 알고리즘** | 배분 후보를 수백 개 만들어 모델에 넣어 보고, 가장 좋은 것을 골라요 | 길을 여러 개 넣어 보고 가장 빠른 길을 고르는 내비게이션 |

```
[운영자 입력] 강종, 폭, 들어오는 두께, 목표 두께
        ↓
[최적화] 배분 후보 하나 만들기 (F1~F4 출측 두께)
        ↓
[AI 모델] 이 배분이면 F1~F5 하중은? → 각 스탠드 이용률 계산
        ↓
[최적화] "가장 힘든 스탠드의 이용률"을 점수로 기록
        ↺ 다른 후보로 수백 번 반복
        ↓
점수가 가장 좋은 배분 = 추천 조건
```

- **모델이 최적 조건을 바로 예측하지 않는 이유:** 데이터에 "정답 배분"이 없어요. 데이터에 있는 건 운영자가 실제로 썼던 배분과 그때의 하중뿐이에요.
- **단조 제약이 중요한 이유:** 최적화는 모델의 답을 그대로 믿어요. 모델에 "압하율을 올리면 하중이 내려간다" 같은 오류가 있으면, 최적화가 그 틈을 좋은 배분으로 착각해 추천할 수 있어요.
