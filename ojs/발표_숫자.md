## 7-1. GBDT 개발 과정과 아쉬운 점
- **튜닝** (출처: [04_gbdt_h1h2.ipynb](04_gbdt_h1h2.ipynb)): 학습률 0.1, 나무 1,400개로 결정
  - ⚠️ 04를 다시 실행한 뒤 맨 아래 "최종 평가" 표의 MAE를 쓰세요. 예전 데이터로 돌렸을 때는 0.46 → 0.39 MN(약 15% 개선)이었어요.
- **단조 제약:** "더 누르면 하중 감소" **7.4% → 0%**, 정확도 손실 MAE 0.415 → 0.444 MN
- **1차 비교** (출처: [02_ai_models.ipynb](02_ai_models.ipynb), 코일 단위 5-fold, 기본 설정): GBDT R² 0.991 / MAE 0.46, MLP 0.988 / 0.55, 하이브리드 0.992 / 0.45
  - 7번 표와 평가 방식이 달라서 같은 표에 섞으면 안 돼요.
- 끝까지 개발(튜닝, 단조 제약, 최적화 연동)한 모델은 **GBDT 하나**예요.
