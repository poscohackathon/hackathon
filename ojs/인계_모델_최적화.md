### 7-1번. GBDT 개발 과정과 아쉬운 점

**GBDT 개발 (가설 → 검증 → 결정)**
- H1 "나무를 늘리면 좋아진다" → 맞음 (600개는 덜 배운 상태)
- H2 "학습률을 낮추면 좋아진다" → 틀림 (같은 나무 수에서 0.1이 가장 좋음)
- 결정: 학습률 0.1, 나무 1,400개 → 처음 보는 코일에서 MAE 0.46 → 0.39 MN
- 단조 제약: "더 누르면 하중 감소" 7.4% → 0%, 정확도 손실 MAE 0.03 MN

**계획과 실제 (발표 문장)**
> - 계획: GBDT, MLP, 하이브리드(물리식 × AI 보정) 세 모델을 비교하려 했어요.
> - 실제: 세 모델 모두 기본 설정으로 1차 비교까지 했어요. 시간 제약으로 **튜닝과 단조 제약, 최적화 연동까지 개발한 모델은 GBDT 하나**예요.

| 모델 | 1차 비교 (기본 설정) | 튜닝 | 단조 제약 | 최적화 연동 |
|---|---|---|---|---|
| **GBDT** | R² 0.991 / MAE 0.46 MN | ✅ | ✅ | ✅ |
| MLP | R² 0.988 / MAE 0.55 MN | - | - | - |
| 하이브리드 (M3 × GBDT 보정) | R² 0.992 / MAE 0.45 MN | - | - | - |

1차 비교: [02_ai_models.ipynb](02_ai_models.ipynb), 코일 단위 5-fold. 2번 표(코일 20% 평가)와 평가 방식이 달라서 숫자를 한 표에 섞지 마세요.

**아쉬운 점과 다음 단계 (발표 문장)**
> - MLP는 기본 설정 그대로예요. 층 수와 학습률을 튜닝하면 GBDT와의 격차가 줄 수 있어요.
> - 하이브리드는 기본 설정에서도 GBDT와 비슷한 성능을 보였어요. 물리식을 뼈대로 써서 설명력이 더 좋은 만큼, 튜닝과 단조 제약을 넣어 최적화에 연결해 보고 싶었어요.
