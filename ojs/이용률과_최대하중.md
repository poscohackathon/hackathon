# 이용률이 줄어도 최대 하중이 늘어나는 이유

- **받는 사람:** 박지해 (시뮬레이터·발표), 김하진 (최적화) 참고
- **작성:** 오정수, 2026-11-10
- **근거:** [05_optimization.ipynb](05_optimization.ipynb), 단조 제약 GBDT + `khj/optimize.py`, 표본 200코일

## 한 줄 요약

최적화 점수가 **하중(MN)이 아니라 이용률(하중 ÷ 스탠드별 기준 하중)** 이라서 그래요. 스탠드마다 기준 하중이 달라서, 기준이 작은 뒷단(F4·F5)의 부담을 기준이 큰 앞단(F1·F2)으로 옮기면 이용률은 줄지만 MN은 늘 수 있어요.

## 1. 이용률이란

**이용률 = 하중 ÷ 그 스탠드의 과거 최대 하중(상위 0.5%)**

| 스탠드 | F1 | F2 | F3 | F4 | F5 |
|---|---|---|---|---|---|
| 기준 하중 (MN) | 36.4 | 33.7 | 23.6 | 19.4 | 14.3 |

- 같은 10 MN이라도 F1에서는 이용률 0.27, F5에서는 0.70이에요.
- 즉 **뒷단은 MN이 작아도 이용률이 높고, 앞단은 MN이 커도 이용률이 낮아요.**
- 실제 설비 정격 데이터가 없어서 과거 최대 하중을 기준으로 삼은 **가정값**이에요.

## 2. 최적화가 하는 일

점수 = **최대 이용률 + 0.5 × 스탠드 간 이용률 편차** (낮을수록 좋음)

이용률이 가장 높은 스탠드(병목)의 부담을 줄이려고 그 스탠드의 압하를 줄이고, 줄인 만큼 다른 스탠드가 더 눌러요. 최종 두께는 같아야 하니까요. 병목이 뒷단이면 앞단이 더 누르게 되는데, 앞단은 원래 하중(MN)이 커서 조금만 더 눌러도 MN이 크게 늘어요.

## 3. 실제 예: 코일 2757

| | F1 | F2 | F3 | F4 | F5 | 최대 이용률 | 최대 하중 |
|---|---|---|---|---|---|---|---|
| 현재 압하율 | 0.160 | 0.220 | 0.216 | 0.198 | 0.130 | | |
| 현재 하중 (MN) | 10.0 | 11.6 | 10.7 | 10.5 | 6.9 | | **11.6 MN** (F2) |
| 현재 이용률 | 0.27 | 0.35 | 0.45 | **0.54** | 0.48 | **0.541** (F4) | |
| 추천 압하율 | 0.195 | 0.271 | 0.183 | 0.152 | 0.118 | | |
| 추천 하중 (MN) | 13.3 | 13.5 | 9.5 | 8.8 | 6.5 | | **13.5 MN** (F2) ⬆ |
| 추천 이용률 | 0.37 | 0.40 | 0.40 | **0.45** | 0.45 | **0.453** (F4) ⬇ | |

- 병목 F4의 압하를 0.198 → 0.152로 줄여 **F4 이용률 0.54 → 0.45 (−16.3%)**
- 대신 F1·F2가 더 눌러서 **F2 하중 11.6 → 13.5 MN**
- F2 이용률은 0.40으로 여전히 낮아서 점수상으로는 "더 균형 잡힌" 배분이에요. 하지만 MN 기준 최대 하중은 늘었어요.

## 4. 얼마나 자주 생기나 (표본 196코일)

| 현재 병목 스탠드 | 코일 수 | 최대 하중(MN)이 늘어난 코일 |
|---|---|---|
| F1 | 46 | 6 (13%) |
| F2 | 64 | 42 (66%) |
| F3 | 31 | 15 (48%) |
| F4 | 45 | 30 (67%) |
| F5 | 10 | 7 (70%) |
| **전체** | **196** | **100 (51%)** |

**병목이 F1인 코일은 대부분 최대 하중도 같이 줄어요.** F1은 하중이 가장 큰 스탠드라, F1 부담을 줄이면 MN 기준 최대 하중도 같이 내려가기 때문이에요. 시연 코일 2744(27.1 → 20.8 MN)와 2599(35.5 → 29.7 MN)가 이 경우예요.

3. **발표에서 이렇게 설명하면 돼요:** "스탠드마다 견딜 수 있는 하중이 달라서, 하중 크기가 아니라 각 스탠드의 여유(이용률)를 기준으로 균형을 맞췄습니다."
4. **피할 표현:** "모든 코일에서 하중을 줄였다" (절반은 MN이 늘어요)

## 6. 점수 기준을 MN으로 바꾸고 싶다면

`khj/optimize.py`의 `optimize()`는 점수 함수를 바꿔 끼울 수 있어요. 최대 하중(MN)을 줄이는 쪽으로 바꾸려면 이렇게 하면 돼요.

```python
def max_force_objective(F, lim):
    return F.max(axis=1) + 0.5 * F.std(axis=1)   # MN 기준

res = optimize(coil, predict_fn, lim, objective=max_force_objective)
```

다만 이 경우 F1·F2의 하중만 계속 줄이려고 해서, 기준 하중이 작은 뒷단(F4·F5)이 과거 최대에 가까워질 수 있어요. 어느 기준을 쓸지는 팀에서 정하면 되고, 지금은 기획서의 "설비 한계 대비 균형"에 맞는 **이용률 기준을 유지**하는 걸 추천해요.
