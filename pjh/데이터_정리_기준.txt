데이터 정리 기준 (pjh)
========================================

대상: main/raw_data/metals.xlsx (시트 "All Grades Data")
      열간압연 사상압연 F1~F5 하중 데이터, 38,980행 (코일 7,797개 x 5 스탠드)
코드: pjh/pjh.ipynb


1. 원본에서 이미 정리된 것 (논문 저자가 한 부분)
----------------------------------------
- 0 이하 값과 결측치 제거 (Grade 2의 코일 2개에서 5행)
- 단위는 전부 SI (하중 N, 길이 mm, 온도 K)


2. 우리가 확인만 하고 손대지 않은 것
----------------------------------------
- 두께 역전 (출구 >= 입구): 0건
- 스탠드별 하중 극단값 (중앙값 +- 4.5 x IQR 밖): 0건 -> 제거하지 않음
- 결측치: 0개


3. 우리가 제외한 것 (코일 단위로 통째로 제외)
----------------------------------------
한 코일은 아래 조건을 만족해야 한다.
  - F1~F5가 한 번씩 있어야 한다.
  - 앞 스탠드 출구 두께 = 다음 스탠드 입구 두께
  - 폭은 코일 안에서 일정
이를 어기는 코일은 행이 코일 사이에서 밀린 것으로 보고 제외한다.

  기준                                          허용 오차   해당 코일
  --------------------------------------------  ---------  ---------
  스탠드 구성이 F1~F5 한 번씩이 아님            -          8
  앞 스탠드 출구와 다음 스탠드 입구 두께 차이   0.01 mm    249
  코일 내 폭 변동                               0.01 mm    261
  합계 (중복 제거)                                         264 (3.4%)

  결과: 7,797개 -> 7,533개 코일
        38,980행 -> 37,665행 (전부 코일당 5행)

  - 행 단위로 고치거나 순서를 복구하지 않음 (틀릴 위험이 있어서)
  - 제외 이유: 압하 배분 최적화는 연속성(F1 출구 = F2 입구)을 전제로 하기 때문
  - 허용 오차 0.01 mm는 우리가 정한 값. 실제 어긋남은 대부분 0.1 mm를 크게
    넘지만, 값을 바꿔서 결과가 달라지는지는 확인하지 않음


4. 알려진 영향과 한계
----------------------------------------
- Grade05: 392개 -> 130개 코일 (262개, 67% 제외)
    소수 강종이라 성능이 불안정할 수 있음
- Grade02: 1,542개 -> 1,540개. 나머지 강종은 변화 없음
- 제외된 코일은 이상한 코일이라기보다 기록이 밀린 코일이다.
  Grade05 외에는 제외로 인한 편향이 작다고 본다.
- 속도, 성분, 윤활 정보는 원래 데이터에 없음
- xlsx가 Strict OOXML 형식이라 pd.read_excel이 시트를 읽지 못함
  -> pjh.ipynb의 load_metals()로 XML을 직접 파싱


5. 모델링 때 지킬 것
----------------------------------------
- 학습/평가는 행이 아니라 코일 단위로 분할
  (한 코일의 5개 스탠드가 학습과 평가에 섞이지 않게)
- 강종별 성능을 따로 확인 (Grade05, Grade10 등 소수 강종)
- 최적화는 관측된 값의 범위 안으로 제한
- "하중 집중"의 기준(최대 하중, 스탠드 간 편차 등)을 직접 정의
- 관측 데이터라서 인과 해석에는 한계가 있음. 압하율 같은 물리 기반 파생 변수 활용
